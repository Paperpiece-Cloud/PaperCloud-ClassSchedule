
# PaperCloud·做纯净的班务系统

为班级 49 人做的班级门户网站：课表、值班、班级管理

**个人以及班级内部使用，哥们还没资源拿出去**

Python 标准库后端 + 原生前端
**不依赖Web框架**，
前端体积8MB左右，所谓烂服务器都带得动

---

## 功能

| 模块 | 说明 |
|---|---|
| **首页** | 页面首屏 |
| **课表** | 周课表，单双周，教师/教室等，可以把ICS丢给日历哦 |
| **班务** | 排个破值日，记各位的电话 |
| **控制台** | 访客统计，在线人数（本来拿给iPhone 7当看板的） |
| **管理后台** | 课表调整，人皇管理等 |
| **快捷调课** | 教室/课时调整|
| **工具箱** | 其实感觉没用哈 |
| **校园全景** | 要怪就怪学校喊的720云，看看还TM收费...... |

---

**后端**

- Python3 标准库：`http.server` / `ThreadingHTTPServer`
- 路由、Cookie 会话、`pbkdf2` 
- gzip（`Accept-Encoding` 协商）
- 数据在JSON里

**前端**

- 原生 HTML / CSS / JavaScript （原生到大肥鱼一看页面只有几个字）
- iOS26/27液态玻璃（`backdrop-filter` + 阴影）
- CSS 动画，轮询数据（加载而已）
  看吧，哪家AI都是一抹黑，前端还是太多了，页面骨架来自大肥鱼

**全景**
*数据是从720云爬出来的，我自己的大疆拍不出来昂*
- WebGL1渲染器
- 拖动/双指缩放，标签还没做好

## 目录结构

```
app/            后端（路由和会话）
web/            页面（页面独立html）
  campus/       全景图，不给你看
  tour2/        全景（场景资源我藏起来啦）
data/           运行时数据（只提交 *.example）
config/         配置（只提交 *.example）
```

##安全
-基础保护来自阿里云
-使用Cloudflare入公网，较宽容限流
-?k作为主页以外其他页面的口令验证

## 本地运行

```bash
python app/server.py
# 监听 http://127.0.0.1:8787
```
